# 광제보드 Windows 설치 프로그램

광제보드 최신 HTML을 Windows EXE 설치 프로그램으로 만드는 전체 프로젝트입니다.

## 데이터 저장 위치

입력 자료는 Windows `문서\광제보드\gwangje-board-data.json`에 자동 저장됩니다.
프로그램을 제거해도 이 자료 파일은 자동으로 삭제되지 않습니다.

## 설치 파일 만드는 방법

1. 이 ZIP의 압축을 풉니다.
2. 압축을 푼 폴더 안의 파일과 폴더를 GitHub 새 저장소에 모두 올립니다.
3. GitHub의 `Actions` 탭을 엽니다.
4. `광제보드 Windows 설치파일 만들기` 작업이 완료될 때까지 기다립니다.
5. 완료된 작업의 `Artifacts`에서 `GwangjeBoard-Windows-Installer`를 다운로드합니다.
6. 다운로드한 ZIP을 풀고 `GwangjeBoard-Setup-1.0.0.exe`를 실행합니다.
